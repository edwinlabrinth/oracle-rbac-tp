\section*{Environnement de travail et conventions}
\addcontentsline{toc}{section}{Environnement de travail et conventions}

Le TP est rédigé pour Oracle Database 19c (CDB \code{ORCL}, PDB \code{ORCLPDB}). Il a été réalisé
sur \textbf{Oracle AI Database 26ai Free (version 23.26.3.0.0)}, exécutée dans un conteneur Docker
(image \code{gvenzl/oracle-free:slim}) hébergé dans un GitHub Codespace. Le conteneur est
une base multitenant (CDB \code{FREE}) ; la PDB utilisée est \textbf{\code{FREEPDB1}}, qui remplace
\code{ORCLPDB} partout dans l'énoncé. Toutes les connexions se font dans la PDB, sauf l'exercice 1.5
(racine \code{CDB\$ROOT}).

Les sessions sont exécutées avec SQL*Plus. Les « captures » de ce rapport sont des rendus d'images
réalisés à partir des journaux (\emph{logs}) réels des sessions ; le nom du journal est rappelé en pied
de chaque image. Quand le résultat obtenu diffère de ce que l'énoncé (version 19c) annonce, un encadré
\emph{Écart par rapport au TP} l'indique et l'explique.
